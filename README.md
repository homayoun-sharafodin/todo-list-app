# Python_To_Do_List_App

A simple command-line To-Do List application built with Python.

This project was created to practice Python fundamentals and GitHub workflow, including repositories, branches, commits, pull requests, and merges.

# Features

- Add new tasks
- View all tasks
- Mark tasks as done
- Delete tasks
- Save tasks in a JSON file
- Load saved tasks when the app starts
- Renumber tasks after deletion
